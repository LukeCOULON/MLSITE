QUESTIONS

Avant de commencer.

Sur quelles plateformes MultiLaunch fonctionne-t-il ? +

La version actuelle de l'installateur prévoit une installation pour Linux et Windows.

Est-ce que MultiLaunch modifie mes jeux ? +

Le scanner de détection fourni dans le projet est documenté comme non destructif : il ne lance pas les exécutables et ne modifie ni les jeux ni les préfixes Wine.

Où sont stockées les données ? +

L'installateur crée un espace de données dans le dossier utilisateur, notamment Documents/MultiLaunch/data.json.
